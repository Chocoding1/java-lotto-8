# java-lotto-precourse

## 기능 목록
1. [입력] 로또 구입 금액 입력받는다.
   - [예외 처리] 구입 금액이 정수 형태가 아닐 경우 예외 메시지를 출력하고 다시 입력받는다. (예외 메시지는 [ERROR]로 시작)
   - [예외 처리] 구입 금액이 1,000원 단위가 아닐 경우 예외 메시지를 출력하고 다시 입력받는다.
2. [중간 과정] 입력받은 구입 금액만큼 로또를 발행한다.
3. [출력] 발행한 로또를 오름차순으로 출력한다.
4. [입력] 당첨 번호를 입력받는다.
   - [예외 처리] 당첨 번호가 6개가 아닐 경우 예외 메시지를 출력하고 다시 입력받는다.
   - [예외 처리] 당첨 번호의 구분자가 쉼표(,)가 아닐 경우 예외 메시지를 출력하고 다시 입력받는다.
5. [입력] 보너스 번호를 입력받는다.
   - [예외 처리] 당첨 번호와 중복될 경우 예외 메시지를 출력하고 다시 입력받는다.
6. [중간 과정] 당첨 로또와 발행한 로또를 비교하여 기록한다.
7. [출력] 당첨 내역을 출력한다. (수익률은 소숫점 둘째 자리에서 반올림)
