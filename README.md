# java-lotto-precourse

## 기능 목록
1. **[입력] 로또 구입 금액을 입력 받는다.**
   - [예외 처리] 정수 타입이 아닐 경우 에러 메시지를 출력하고 재입력 받는다.
   - [예외 처리] 1000원 단위로 나누어 떨어지지 않을 경우 에러 메시지를 출력하고 재입력 받는다.
2. **[중간 과정] 로또를 발행한다.**
   - 로또 번호는 오름차순 정렬
3. **[출력] 발행한 로또를 출력한다.**
4. **[입력] 당첨 번호를 입력 받는다.**
   - 로또 객체를 생성한다.(LottoParser)
     - [예외 처리] 번호 개수가 6개가 아닐 경우 에러 메시지를 출력하고 재입력 받는다.
     - [예외 처리] 번호가 1 ~ 45 사이의 숫자가 아닐 경우 에러 메시지를 출력하고 재입력 받는다.
     - [예외 처리] 중복된 번호가 존재할 경우 에러 메시지를 출력하고 재입력 받는다.
5. **[입력] 보너스 번호를 입력 받는다.**
   - [예외 처리] 정수 타입이 아닐 경우 에러 메시지를 출력하고 재입력 받는다.
   - [예외 처리] 번호가 1 ~ 45 사이의 숫자가 아닐 경우 에러 메시지를 출력하고 재입력 받는다.
   - [예외 처리] 당첨 번호 내에 중복된 번호가 존재할 경우 에러 메시지를 출력하고 재입력 받는다.
6. **[중간 과정] 수익률을 계산한다.**
7. **[출력] 당첨 내역을 출력한다.**
   - 일치 여부, 수익률 필요
